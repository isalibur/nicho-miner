# Minerador de Nichos para YouTube

Este repositório contém um pipeline que coleta dados de tendências, palavras‑chave e métricas de concorrência para identificar nichos lucrativos no YouTube.

## Etapas do Projeto
1. **Coleta** – APIs do YouTube, Google Trends e Ahrefs/SEMrush.
2. **Processamento** – Normalização e cálculo de score.
3. **UI** – Dashboard em FastAPI/Streamlit.
4. **Deploy** – Docker + GitHub Actions.
